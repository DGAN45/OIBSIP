## 📖 Overview

This project develops a **Machine Learning Regression Model** capable of predicting the selling price of used cars based on various vehicle specifications.

The notebook demonstrates a complete machine learning workflow, including data preprocessing, exploratory data analysis (EDA), feature engineering, model training, evaluation, and prediction using Python and Scikit-learn.

---

# 🎯 Objectives

- Analyze the used car dataset.
- Clean and preprocess the data.
- Perform exploratory data analysis (EDA).
- Convert categorical variables into numerical features.
- Train a regression model to predict car prices.
- Evaluate model performance using regression metrics.
- Predict prices for unseen vehicles.

---

# 📂 Dataset

**Dataset:** CarDekho Used Car Dataset

The dataset contains information about previously owned vehicles.

| Feature | Description |
|----------|-------------|
| Name | Car Model |
| Year | Manufacturing Year |
| Selling Price | Target Variable |
| Kilometers Driven | Distance Travelled |
| Fuel | Fuel Type |
| Seller Type | Dealer or Individual |
| Transmission | Manual or Automatic |
| Owner | Ownership History |
| Mileage | Fuel Efficiency |
| Engine | Engine Capacity |
| Max Power | Engine Power |
| Seats | Number of Seats |
